Origen del inventario prestado: es inventario propio de Más Tech (WFM) prestado a usuarios internos para pruebas de red (§15.10 "WFM inventory loan for network testing" · RF 4.1.1). No sale del stock de campo de un contratista y no genera documento SAP — el préstamo es control operativo interno + notificaciones (sin 351/101/221/501). La ubicación de origen exacta del equipo (bodega principal / pool de testing / recuperado ‑R) no está especificada en la spec → a confirmar con el cliente.
